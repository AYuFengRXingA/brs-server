# BRS 服务器 · 宣传页

一个「PPT 式」的滚动宣传页：全屏分页、翻页动画、逐元素入场、3D 卡片、终端模拟、WebAudio 合成音效。
纯静态、零依赖、无外链素材，双击 `index.html` 就能看。

---

## 打开

- **直接双击 `index.html`**（推荐 Chrome / Edge / Firefox 新版）。
- 也可以放到任意静态服务器上：
  ```bash
  # 任意一种都行
  python -m http.server 8080
  ```
  然后访问 `http://localhost:8080/brs-promo/`。

> 声音需要浏览器一次点击才会解锁：进页面先点「点击进入」。
> 如果没有声音，点右下角「声音」按钮或按 `M` 检查是否静音。

## 操作

| 操作 | 效果 |
| --- | --- |
| 滚轮 / `↑` `↓` / `空格` / `PageUp` `PageDown` | 上一页 / 下一页 |
| `←` `→` | 上一页 / 下一页 |
| 右侧圆点 | 直接跳页 |
| `Home` / `End` | 回封面 / 到最后一页 |
| `M` | 静音切换 |
| `P` | 自动播放（13 秒一页） |
| `F` | 全屏 |
| `?` | 快捷键面板 |
| 手机 | 上下滑动翻页；内容超长时先滚动内容 |
| 网址 `#skip` | 跳过开机动画直接进入 |
| 网址 `#skip&s=5` | 直接进入第 5 页（做素材/调试用） |

页面里的交互：点 IP 卡片复制、点指令按钮或直接在终端里敲指令、右上角/右下角的按钮、赞助名单跑马灯（悬停暂停）。

## 改文案

文案都在 `index.html` 里，一页一个 `<section class="slide">`，找注释最快：

```
<!-- 01 封面 -->  … <!-- 09 结尾 -->
```

常用位置：

| 想改什么 | 去哪找 |
| --- | --- |
| 标题 / 描述 | 各 `section` 里的 `<h1 class="hero">`、`<h2 class="s-title">`、`<p class="s-sub">` |
| Java / 基岩 IP | 08 页（`data-id="join"`）里的 `data-copy="..."` 和显示的地址 |
| QQ 群号 | 08 页的 `data-copy="808637100"`、09 页的复制按钮 |
| 赞助名单 | `assets/js/main.js` 里的 `sponsors` 数组 `[['昵称','金额'], …]` |
| 终端指令 | `assets/js/main.js` 里的 `CMDS` 对象，加一条就是一个新指令 |
| 每页小标题（右侧导航） | `section` 上的 `data-title="玩法"` |
| 动画顺序 | 元素上的 `style="--i:3"`，数字越大出现越晚 |

改完刷新即可，没有构建步骤。

## 内容来源与口径

- 所有信息来自《BRS服务器文档》（版本 1.21.8、IP、指令、配置、账目、赞助名单等）。
- **账目页**的数字与文档一致：收入 964.97 / 支出 597.76 / 月均 ≈50 / 结余 267.21。
- **赞助名单是节选**（页面上也标了「节选」），页内不展示加总，避免和文档总计口径不一致。
- 文档里没有的运营数据（在线人数、开服天数等）一律没有编造，页面上的数字都有出处。
- 页脚标注了「本页信息以群内文档为准 · 宣传展示用」。

## 几个实现细节

- **音效**：全部用 WebAudio 现场合成（正弦/三角/方波 + 噪声扫频），没有 mp3，
  所以文件很小、也不会涉及版权。环境音是一层低频铺底 + 随机五声音阶的「星点」音。
  静音状态记在 `localStorage`。
- **背景**：`<canvas>` 手绘的星空、飘浮方块和两层像素地平线，鼠标移动有视差，翻页时地平线会轻微位移。
- **终端**：`/home`、`/warp`、`/flyplayer`、`/bot list`、`/co i`、`/tps`、`/gc` 等都有对应回复，
  输入 `help` 看列表，输入 `op` 之类的会有彩蛋。
- **性能**：动画以 `transform` / `opacity` 为主，`prefers-reduced-motion` 下会自动减弱。
- **响应式**：≤900px 单列布局，≤640px 隐藏背景方块、卡片单列。

## 部署

纯静态，把整个 `brs-promo` 文件夹丢上去即可（GitHub Pages、Vercel、Netlify、宝塔、Nginx 都行）。
没有后端、没有接口、没有第三方请求，内网/离线也能跑。
